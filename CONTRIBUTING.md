# Contributing

Thanks for your interest in improving Roast My GitHub.

## Development

1. Fork the repository.
2. Create a focused feature branch.
3. Install dependencies with `npm install`.
4. Add or update tests where practical.
5. Run the project locally with `npm run dev`.
6. Open a pull request with a clear description of the change.

## Guidelines

- Keep changes focused and readable.
- Never commit API keys or `.env` files.
- Preserve the separation between deterministic scoring and AI-generated commentary.
- Document meaningful behavior changes.
